WHAT IS STEGANOGRAPHY?

The art of hiding secret information inside ordinary-looking files — in this case, images.

HOW IT WORKS (LSB METHOD)

Every pixel has R, G, B values (0–255), each stored as 8 bits, e.g. 200 → 11001000. We change only the last bit (Least Significant Bit): 200 → 11001001 = 201. The change is invisible to the human eye. Encoding 1 bit per channel × 3 channels per pixel lets us hide large messages in any image.

CAPACITY FORMULA

Max characters = (width × height × 3) / 8

IMPORTANT

✅ Always use PNG images (lossless compression).
❌ JPEG will destroy hidden data (lossy compression) — downloaded output is always PNG.
